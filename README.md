# Sophienix's Hub

## Tabs

- **Info** — Welcome message, credits, and helpful links.
- **Gallery** — Add images by URL or upload them from your computer. Click **Save Image** to keep an image. Each image has buttons for copying the link, copying the image, downloading it, and hiding/showing it. If you select an image file from your computer, **Copy L** copies a local-storage/data link that may not work when sent to someone else. Use an online image URL if you need to share the link.
- **Url** — Save website links with a title and category. Each saved link has **Open**, **Copy**, **WebUI**, and delete buttons.
- **Notes** — Save text notes. Notes can be copied, hidden, or deleted.
- **WebUI** — Enter a WebUI address in Settings, then open it here.
- **Settings** — Change colors, clock format, background, WebUI address, and saved gallery behavior.

## Website status checker

Saved URL cards show a status dot:

- Green means the site responded.
- Red means it could not be reached.
- Grey means it is currently being checked.

The checker runs automatically and can also be started with the **Refresh** button above the saved URLs.

## Saving and resetting

Data is saved in this browser’s local storage, so it is specific to the browser and computer being used. The **Delete All Saves & Reset Theme** button removes saved links, notes, gallery images, and custom settings.

## Important note

Some websites may not load inside the WebUI tab because of login, iframe, or security restrictions. If that happens, use the link’s **Open** button instead.
